# CLAUDE.md

## Project Overview

This repository is the official public website for Scent Memory.

Its current purpose is to provide public pages required for App Store release:

- Privacy Policy
- Terms of Use
- Support
- Minimal home page

This website may later become the official Scent Memory landing page.

## Design Direction

The website should visually match Scent Memory:

- warm off-white background
- quiet
- minimal
- refined
- generous whitespace
- highly readable typography
- minimal borders and shadows
- no loud gradients
- mobile-first
